# 便利店交班稽核台

- 行业：石油（加油站附属便利店）
- 技术栈：Vue3、Vite、TypeScript（零新增依赖）
- 启动：`npm install && npm run dev`
- 构建：`npm run build`

## 功能

每班登记**店内销售额、券码核销、实盘库存**，并执行交班稽核：

1. **券码唯一（R-COUPON-UNIQUE）**：同一券码跨班只计一次；已被其他班次核销的券码再次提交即冲突。
2. **重复整班拒绝（R-COUPON-DUP）**：单次提交内同一券码出现多次，整班拒绝，任何数据不落库。
3. **盘亏盘盈定性（R-INV-REASON）**：实盘与账面不符必须选择「损耗 / 错录 / 盗损」并填写依据，未填不得复核。
4. **复核冻结（R-FROZEN）**：已复核班次冻结；更正只能带原因新建版本，历史原值完整保留，班次回到待复核。
5. **冲突稽核中心**：刷新后班次、券码占用、库存定性与版本链保持一致，逐条列出班次、券码/对象、差额与触发规则。

数据持久化在浏览器 localStorage。

## 分层

| 层 | 目录 | 职责 |
| --- | --- | --- |
| 数据 | `src/data/` | 领域类型 `types.ts`、商品目录 `catalog.ts`、种子数据 `seed.ts`、唯一读写入口与持久化 `store.ts` |
| 规则 | `src/rules/auditRules.ts` | 全部业务规则，纯函数，输入数据输出结论，不依赖 Vue 与存储 |
| 页面 | `src/App.vue`、`src/ui/` | 表单、班次卡片、冲突中心，只做采集与展示 |
