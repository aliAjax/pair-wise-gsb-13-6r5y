# 加油站便利店交班稽核台

- 行业：石油 / 零售
- 技术栈：Vue3、Vite、TypeScript（纯 Vue 组合式 API + 原生 CSS，**不增加任何依赖**）
- 启动：`npm install && npm run dev`
- 构建：`npm run build`

## 功能

每班登记**店内销售额、券码核销、实盘库存**，并在此基础上提供完整稽核闭环：

1. **券码唯一**：同一券码跨班只计一次；重复提交（含班内重复、跨班占用）整班拒绝，不落任何半截数据。
2. **盘亏/盘盈定性**：实盘与账面有差异时，必须选择「损耗 / 错录 / 盗损」并填写依据，未定性或缺依据不得复核。
3. **复核冻结**：已复核班次写入校验值并冻结；列表中不可再编辑。
4. **更正版本化**：已复核班次只能带更正原因新建版本（v2、v3…），原版本连同原值、原定性、原依据原样保留，新版本重新走复核。
5. **刷新一致性**：班次、券码、库存、版本链整体存于 localStorage 一个带版本号的信封；每次加载全量重算稽核，冲突表列出**班次、券码、差额、触发规则**及说明：
   - R01 必填项校验 / R02 数值合法性
   - R03 同一券码跨班只计一次
   - R04 盘亏盘盈须定性并写依据
   - R05 已复核班次冻结 / R06 更正必须带原因并保留原值
   - R07 冻结数据一致性校验（checksum，防止绕过页面改数据）

页面顶部提供「恢复演示数据」，可随时回到含已复核冻结、待复核待定性、更正版本链三种形态的种子数据。

## 分层结构（数据 / 规则 / 页面分开）

```
src/
├─ audit/
│  ├─ types.ts    领域类型：班次、版本、券码、库存行、冲突
│  ├─ rules.ts    业务规则：纯函数校验、冻结 checksum、全量稽核
│  ├─ storage.ts  数据层：localStorage 信封读写 + 种子数据
│  └─ store.ts    应用编排：把数据层与规则层粘合为页面动作
├─ components/
│  ├─ ShiftFormPanel.vue  登记 / 更正表单（整班校验反馈）
│  ├─ ShiftList.vue       班次卡片、版本链、复核入口
│  └─ ConflictTable.vue   刷新一致性稽核冲突表
└─ App.vue                页面装配：指标、筛选、布局
```

规则层不依赖 Vue 与 DOM，可独立单测；页面只调 `useAuditStore()` 的动作，不直接实现任何业务判定。
